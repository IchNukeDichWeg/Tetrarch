# Which net plays which mode and setup. One `mode setup netfile` per line;
# netfile is relative to this directory. Every Teams setup must appear and
# every net named must exist -- selftest.py checks both, because a typo here
# silently sends a setup to the fallback net, which is the mistake this file
# exists to prevent. A two-field line is read as Teams, so a bundle written
# before FFA existed still means what it meant.
#
# WHY THIS EXISTS. The nets differ by what they were trained on and it matters
# more than expected. net-v5 saw 125,000 classic games and nothing else;
# net-v7 saw 25,000 of each of the five. Head to head over 20,000 games,
# split by setup (docs/AB.md):
#
#     classic  -23.68 +/- 10.21   v5, clearly
#     modern   +22.15 +/- 10.81   v7, clearly
#     by        -3.17 +/- 10.63   level
#     byg       +5.76 +/- 10.72   level
#     rg        -2.56 +/- 10.71   level
#
# Two setups separate and three do not. `modern` is what chess.com has run
# since 2022, so shipping v5 everywhere costs 22 Elo on the variant nearly all
# games are played in.
#
# This whole file is a stopgap. One net that beats v5 on classic AND v7 on
# modern is the right answer; that is a training problem, not a dispatch one.
teams classic net-v5.nnue
teams modern  net-v7.nnue
teams by      net-v7.nnue
teams byg     net-v7.nnue
teams rg      net-v7.nnue

# FFA plays net-ffa1, which is the first net trained on FFA self-play. Against
# the hand eval it was playing before, on a 20,000-position FFA book:
#
#     fixed nodes 20,000   +67.35 +/- 10.38   2,500 games
#     fixed time 200ms     +18.30 +/- 14.88   1,571 games
#
# NOT a confirmed release: fixed time is the instrument that decides and 1.23
# sigma does not clear it. It is bundled anyway because the bundle is dispatch,
# not a claim -- the alternative here is the hand eval, and the net beat it at
# both instruments and on every setup.
#
# It was trained on `classic` self-play alone, which is exactly the mistake the
# Teams half of this file records for net-v5. It does not repeat it. Split by
# setup at fixed nodes: classic +89.71, rg +83.61, modern +65.22, by +60.36,
# byg +36.88, all +/- ~23. Weakest where it never trained, positive everywhere.
# At fixed time all five are positive too, none individually significant.
#
# Do NOT let FFA fall back to the default net if these lines are removed: the
# default is a Teams net, net-v5 screened at -124.50 +/- 49.31 in FFA, and
# uci.py drops to the hand eval and says so rather than pretending otherwise.
ffa classic net-ffa1.nnue
ffa modern  net-ffa1.nnue
ffa by      net-ffa1.nnue
ffa byg     net-ffa1.nnue
ffa rg      net-ffa1.nnue
